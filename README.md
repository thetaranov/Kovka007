# Kovka007 - Конструктор навесов и ворот v2.0

Профессиональный 3D-конфигуратор навесов и ворот с автоматическим расчетом снеговых и ветровых нагрузок по СП 20.13330.2016, генерацией CAD-чертежей в формате DXF и интеграцией с Telegram.

## 🚀 Возможности

- **3D-визуализация** навесов и ворот в реальном времени
- **Автоматический расчет нагрузок** по СП 20.13330.2016:
  - Снеговые нагрузки (8 снеговых районов России)
  - Ветровые нагрузки (7 ветровых районов)
  - Рекомендации по сечению столбов, высоте ферм и шагу прогонов
- **Генерация CAD-моделей** в формате DXF (AutoCAD, NanoCAD, КОМПАС)
- **Спецификация материалов (BOM)** с весами и длинами
- **Конструктор ворот**: откатные, распашные, навесные
- **Парсинг цен** из Google Sheets
- **Telegram-интеграция**: заявки прямо в мессенджер прораба

## 📋 Требования

- **Node.js** 18.0.0 или выше
- **npm** 9.0.0 или выше (идет в комплекте с Node.js)

## 🛠️ Установка

### Шаг 1: Установка Node.js

1. Скачайте Node.js с официального сайта: https://nodejs.org/
2. Выберите версию **LTS** (рекомендуется)
3. Запустите установщик и следуйте инструкциям
4. После установки перезапустите терминал/VS Code

Проверьте установку:
```bash
node --version  # должно показать v18.x.x или выше
npm --version   # должно показать 9.x.x или выше
```

### Шаг 2: Установка зависимостей

```bash
cd Kovka007
npm install
```

### Шаг 3: Запуск проекта

```bash
npm run dev
```

Или используйте готовые скрипты для Windows:
- **start.bat** - запуск в режиме разработки
- **build.bat** - сборка для продакшена

## 🌐 Доступ к приложению

После запуска откройте в браузере:
- http://localhost:5000

Для доступа с телефона (в одной Wi-Fi сети):
- http://[IP-адрес-компьютера]:5000

## 🔗 Интеграция с Telegram

Приложение работает как Telegram WebApp и отправляет заявки напрямую боту @Kovka007bot.

Формат данных заказа:
```json
{
  "id": "ORD-240115-A3X5",
  "type": "gable",
  "width": 4.5,
  "length": 6.0,
  "height": 2.1,
  "loads": {
    "snow": 336,
    "wind": 304,
    "total": 361
  },
  "price": 127000,
  "cad_dxf": "BASE64_ENCODED_DXF"
}
```

## 📐 CAD-экспорт

DXF-файлы включают:
- Столбы (профильная труба)
- Фермы (верхний/нижний пояс, стойки, раскосы)
- Прогоны
- Связи жесткости
- Спецификацию материалов

Совместимость:
- AutoCAD 2018+
- NanoCAD
- КОМПАС-3D
- FreeCAD
- LibreCAD
